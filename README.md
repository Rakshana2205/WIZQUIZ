# 🧙 WizQuiz

A magical quiz game built with React! Test your knowledge across 5 categories with a timer, streaks, high scores and sound effects!

## 🎮 Live Demo

[Play WizQuiz here](https://wizquiz.vercel.app)

## ✨ Features

- 🔬 5 Quiz categories — Science, Geography, Maths, History, Movies
- ❓ 10 random questions every session
- ⏱️ 15 second timer per question
- 🔥 Streak counter for consecutive correct answers
- 💾 High scores saved per category
- 🎊 Confetti explosion on perfect scores
- 🔊 Sound effects on every interaction
- ⏳ Magical loading screen
- 📱 Fully mobile responsive

## 🛠️ Built With

- React 18
- CSS3 Animations
- Web Audio API
- localStorage API

## 🚀 Getting Started

1. Clone the repo
   git clone https://github.com/Rakshana2205/WIZQUIZ.git

2. Install dependencies
   npm install

3. Start the app
   npm start

4. Open http://localhost:3000
